## 同是香港VPS，99 元/年、HK$80/月、HK$2,160/年差在哪

拿三个真实档位摆在一起，价差来源一眼能看出来。

**99 元/年这一档**（野草云香港轻量）：双核 / 512MB 内存 / 10GB 硬盘 / 500GB 到 1500GB 流量。内存只有 512MB，跑一个静态站或者轻量面板刚好，装带数据库的完整应用会吃紧。续费规则是购买起 2 年内同价，之后随成本调整。

差价最大的一组是 HK$16/月和 HK$180/月，差 11 倍。后者内存 4GB、带 500GB 硬盘，看着配置高，但每月 50GB 流量在稍微有点访问量的站上很快就用完。内存买大了、流量买少了，是香港 VPS 最常见的一种错配。

## 三处容易多付的钱：设置费、管理费、流量超额

标价之外的三类支出，下单页上不一定显眼。

**设置费**。Nethub 六个套餐每个都收 HK$500 Setup Fee，这笔钱不进月费，也不退。同一个商家还有计价周期差异：12 个月预付折算 HK$180/月，3 个月预付折算 HK$240/月，周期越短单价越高。

**管理费**。Host Hong Kong 明确写明 KVM VPS 为 unmanaged，客服支持需要额外付费，管理服务通常按小时计费。远程操作在工作时间收 HK$500/小时另加 HK$500，非工作时间 HK$1,000/小时另加 HK$1,000。Nethub 的 VPS 管理服务是 HK$800/月，重装系统 HK$300/次，数据恢复 HK$300/次。买 unmanaged 就要接受自己动手，否则这笔钱迟早要出。

**流量超额**。Nethub 加 50GB 月流量要 HK$200，加 4GB 内存 HK$100/月，加一个独立 IP HK$100/月。Host Hong Kong 加 1TB 流量是 HK$50/月。同样是 1TB 量级的补充，两家的单价差出几十倍，说明"流量单价"本身要单独比。

附加 IP 也是隐藏成本。Host Hong Kong 单个附加 IP 是 HK$25/月，/29 子网 HK$160/月，/24 子网 HK$3,840/月。需要多 IP 的业务，这部分开销可能超过 VPS 本身。
